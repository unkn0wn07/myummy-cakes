# 🎂 MYummy Cakes — Cake Shop Website

> **Made With Love, Baked To Perfection**

A cake shop website built with React 18 + Vite, featuring a full product catalog, animations, and WhatsApp integration.

---

## 🛠 Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React 18 + Vite |
| Styling | Tailwind CSS v3 |
| Animations | Framer Motion |
| Routing | React Router v6 |

---

## 🚀 Quick Start

### Prerequisites
- Node.js 18+
- Git

### Install & Run

```bash
cd client
npm install
npm run dev
# App at http://localhost:5173
```

---

## 📄 Pages

| Route | Page |
|---|---|
| `/` | Home (hero, featured products) |
| `/menu` | Product catalog with filters |
| `/products/:slug` | Product detail page |
| `/about` | Brand story |
| `/contact` | Contact form |
